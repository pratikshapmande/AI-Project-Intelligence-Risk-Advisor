# Milestone Scope and Acceptance Checklist

Based on the uploaded project brief, Milestone 1 covers study notes, system design, document ingestion, and RAG indexing.

- [x] Study notes for RAG, multi-agent design concepts, and project-management fundamentals
- [x] Architecture document and component responsibilities
- [x] Document data model
- [x] PDF, DOCX, CSV, and TXT text extraction implementation
- [x] Text chunking
- [x] Embedding generation through Sentence Transformers
- [x] ChromaDB persistent vector indexing
- [x] Retrieval endpoint for testing the indexed knowledge base
- [x] React UI for upload, index status, inventory, and retrieval
- [x] Unit tests for core extraction/chunking cases

## Explicitly not implemented
- Scope and deliverable extraction agent
- Risk detection and delivery forecasting agent
- Blocker/action-item identification agent
- Documentation generation agent
- Project health scoring
- Full conversational project intelligence assistant
- Generated risk summary dashboard

The architecture and study notes discuss the broader design context, but those later modules are not presented as working features.
