# Document Data Model — Milestone 1

## Upload-level fields
| Field | Description |
|---|---|
| `document_id` | Random unique ID assigned per upload |
| `source` | Original filename |
| `file_type` | pdf, docx, csv, txt |
| `metadata` | Extraction-specific details such as page count, row count, or columns |

## Chunk-level fields in ChromaDB
| Field | Description |
|---|---|
| `id` | Unique chunk key: document ID plus chunk index |
| `document_id` | Parent upload ID |
| `source` | Source filename |
| `file_type` | Source format |
| `chunk_index` | Zero-based chunk number |
| `document_metadata` | String representation of extraction metadata |
| `document` | Text chunk |
| `embedding` | Vector generated by the configured embedding model |

## Chunking defaults
- Maximum target chunk size: 900 characters
- Overlap: 150 characters
- Chunks prefer a nearby whitespace boundary when possible

These values are starter settings for the milestone and can be tuned after evaluating retrieval quality.
